# Prospective identification protocol, R8

No participants were recruited, data collected or results estimated. This is a proposed sandbox design.

1. Freeze a named-source version pair, routing process, potential faults, independent binary-verdict technology, downstream loss/exposure rule and physical correction menu. Compare provenance timing within the SAME prior-repair and workflow cell. Prior repair changes fault distributions, so comparing different repair cells is not a matched-error test.
2. Randomize early source-map release versus the same map released after a locked check/no-check choice. Release the late map even if the check was skipped. Record offered timing as treatment; unauthorized pre-release map access is noncompliance, not an alternative information set.
3. Independently randomize planned source-repair assignment or availability if estimating the repair interaction. AI-access offer is optional. An access ITT is not a committed-workflow interaction; conditioning on chosen AI, chosen audit or lookup is selection. A two-by-two bundled corpus intervention cannot identify source repair, provenance and structural reformatting separately.
4. Preserve source/version identifiers, map-release timestamps, check choice/time, verdict, named replacements and a separate reserved downstream correctness measurement. In saturated repaired cells, the predicted distinction is auditing the unrepaired route only under early lineage. Marginal task accuracy alone cannot distinguish early/late/opaque histories. Equal check totals in unrepaired cells do not exclude better correction targeting.
5. Maintain slack resources for this matched-information test. If auditing uses a shared constrained pool, individual assignment can interfere with other tasks. Then randomize entire pools/time blocks and define cluster ITT; do not silently apply the batch-separable estimand. Source faults shared across batches also change the independence assumptions.
6. Test alternative explanations: origin resolution embedded in the truth verdict; corrected full content delivered at no extra cost; cheap repair available for both sources; inaccurate lineage; or unrestricted sequential direct source testing. Each changes a material primitive. A null filtering effect can falsify the modeled channel rather than be renamed success.

Report access, timing and repair ITTs separately from model-conditioned interactions; preregister exclusions, stopping and multiple comparisons before any real study. No effect size, power or real-firm result is asserted here. The archived R7 prospective protocol is retained separately for its capacity-interference institution.
